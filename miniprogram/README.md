# 知习 · 微信小程序本地学习首版

**状态：0.1.0-local，开发首版，未上架；不是完整 Android App 移植。**

[完整可行性 / WorkBuddy / 个人主体上架调研](../docs/WECHAT_MINIPROGRAM_RESEARCH.md) · [微信技术能力附录](../docs/WECHAT_TECHNICAL_NOTES.md)

## 已实现

- 原生 WXML / WXSS / CommonJS JavaScript，无第三方运行时或 npm 安装需求。
- 学习 / 复习 / 我的三导航，课程详情、学习资料详情、手动表单、隐私说明，共7页面+自定义TabBar。
- 本地新增课程、手动文本资料、标记疑问、填写/修改手工答案、创建手工复习卡；来源可回到原始资料。
- 四档间隔复习、翻卡、到期队列、评分日志，明确 **非 FSRS**。
- 逐级软归档、回收站恢复，不永久删除；保留历史评分。
- 本地 JSON 备份生成→用户另行点击选择微信会话保存；从会话选择可信备份合并，冲突拒绝而非覆盖。
- 400ms淡入/轻位移、420ms翻卡、按压反馈；减少动态效果选项。
- UUID关联、版本化快照、白名单导入校验、容量限制、存储失败回滚、中文错误消息。

课程/资料/卡片目前不支持完整编辑、搜索、七分类或词表导入，只有疑问答案可修改。不要把新增/查看/归档写成完整CRUD。

## 明确没有实现

云端AI学习包、实时/离线语音识别、后台录音、实时翻译、PDF/OCR、App的FSRS、系统TTS、CET6批量词表、微信登录/短信账号、云同步、订阅消息/日历、桌面组件、Android/网页数据库直接导入、Skyline/Worklet/真实玻璃折射。

本版无 `wx.request/uploadFile/connectSocket/login/getRecorderManager` 等主动云端/录音调用；没有可远程打开的隐藏AI入口。**当前本地数据流说明只适用于此版本。**

## 本地打开

1. 安装官方微信开发者工具（本轮机器已有），选择导入此 `miniprogram/` 目录。
2. `project.config.json` 中 `touristappid` 只是无真实身份的占位，**本机当前工具已拒绝它**，提示 `code 10: 不存在此 AppID`。请使用你本人有开发权限的小程序 AppID，在本机工具内设置；本轮没有替你注册账号或借用其他项目 AppID。
3. AppID不是AppSecret。**不要把AppSecret、身份证、短信验证码、令牌或生产密钥放进源码/聊天。**本地私有开发者配置 `project.private.config.json` 已忽略。
4. 不需要配置云开发、业务域名、模型密钥，不需要 `npm install`。若以后启用云能力，须另做资格与合法通信域名等核验，不要通过关闭域名检查假装正式环境已可用。
5. 默认数据为空；首页“先看看合成示例”需确认后添加，只有完全空库可添加，不覆盖已有数据。

本地分支为 `feat/wechat-miniapp`；未commit、push、开PR、上传体验版或正式发布。

## 验证命令

在仓库根目录执行（Node 20+，本轮使用24.14.0）：

```bash
node --test miniprogram/tests/*.test.cjs
node miniprogram/tools/check.cjs
```

也可进入 `miniprogram` 后执行 `npm test`、`npm run check`，无需先安装依赖。

Windows本机已有微信编译器时，可做离线模板/样式编译：

```bash
node miniprogram/tools/compile-native.cjs "C:/Program Files (x86)/Tencent/微信web开发者工具/resources/app.asar.unpacked/node_modules/wcc-exec"
```

脚本只调用指定位置已安装的 `wcc.exe/wcsc.exe`，输出到被忽略的 `artifacts/`。这不是完整IDE打包命令，不上传文件，不提交审核。

## 数据与可靠性

`lib/store.js` → 纯同步业务仓库，`lib/repository.js` → 惰性wx适配，storage key `zhixi.miniprogram.offline.v1`。

快照：`{version:1,scheduler:'spaced-interval-v1',settings,courses,sessions,doubts,cards,logs}`。每条实体有UUID、创建/更新时间、`deletedAtMillis`；全部关联用UUID。随机UUID回退仅作记录ID，**不是认证凭据**。

- 新版本数据/坏JSON/错误日期、关系、枚举、评分历史会拒绝，**不会静默清空旧库**。
- 写入先克隆草稿、完整校验、单key写入，再发布内存。适配层假设 `setStorageSync` 成功替换单key或失败不写入；不是跨多个key事务。
- 单快照硬限750KiB UTF-8，备份输入≤1MiB；课程100、资料500、疑问1000、卡2000、日志5000，并另受总字节限制。课程/教师/语言80字，资料标题120字、正文30000字，疑问原文/备注/卡片正面2000字、答案/背面4000字。
- 先归档关联卡片、疑问、资料，再归档课程；恢复先父级。评分日志不阻止归档卡片；归档卡片的历史统计隐藏，恢复后排期/历史不回退。
- 完全相同的导入ID跳过；任何内容冲突整批拒绝；保留本机设置，不做自动跨版本迁移/多设备LWW。
- **回收站也占容量，软归档不释放存储。**当前容量不足应先导出保管；将来扩展到版本化分片/文件库。不能作为大规模课堂数据库长期无界使用。
- 微信本地缓存可能被清理；备份未加密且含回收站；生成的文件可能留在微信沙箱。仅生成文件不等于异地备份，需要用户实际保存到可取回位置。

### 间隔规则（非FSRS）

所有下次时间从本次实际评分开始，最长365天：

| 评分 | 间隔 |
|---|---|
| 不认识 / again | 1分钟 |
| 模糊 / hard | 至少10分钟，或原间隔×1.2（向上取整） |
| 认识 / good | 至少1天，或原间隔×2 |
| 很简单 / easy | 至少3天，或原间隔×3 |

只有到期、未归档卡可评分；一轮队列不无限插回“不认识”卡，稍后可“检查新到期卡片”。时间是本机时间，不宣称防作弊或后台提醒。

## 人工验收脚本

1. 空库首页创建合成测试课程，不使用真实教师/学生数据。
2. 新增文本资料→标记疑问→填写答案→从资料创建卡片；课程详情检查数量与来源。
3. 复习：答案未揭示不能评分，翻面后连续点击不能重复评分；切页再回来、重启后排期/日志仍正确。
4. 减少动画打开后，重新进入页面与翻卡不应再播放过渡；测长标题/长答案/键盘/安全区。
5. 尝试直接归档有子项课程，应明确拒绝；按卡片→疑问→资料→课程顺序归档，再从我的逆序恢复。
6. 生成备份不会自动发送；另点保存并选择可信会话。取消导出/选文件/分享均能继续操作。
7. 在独立测试副本导入并核对实体、关联、评分、回收站；重复相同备份跳过，冲突/超大/损坏备份拒绝且旧资料不变。
8. 无网时整个本地闭环可用。真实微信文件选择/分享可能依赖平台状态，不能把Node mock当成已验收。
9. 若存储写满/写失败，表单不得跳走或提示成功，旧数据保持；不能为通过测试清除用户数据。
