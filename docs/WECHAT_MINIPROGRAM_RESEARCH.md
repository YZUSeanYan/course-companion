# 知习微信小程序：可行性、还原度与个人主体上线调研

调研日期：2026-11-11。对象：[YZUSeanYan/course-companion](https://github.com/YZUSeanYan/course-companion)。用户已选择**个人主体**。本报告区分源码事实、官方规则、工程估算和实际交付，不构成平台审核承诺或正式法律意见。

## 一、结论先行

**可以开发，但不能把 Android APK/Compose 或现有 H5 “打包一下”就得到等价、免审的小程序。**

1. 推荐真正的原生 WXML/WXSS/JS 小程序，复用知习的产品流程、品牌与后端协议规格，而不是直接复用 Compose 界面代码。
2. WorkBoddy 很可能指腾讯 **WorkBuddy**。其官方文档确有原生小程序生成、第三方平台托管上传、提审、发布能力；**正式版依然需要备案、平台审核及主体相关检查**。工具代办流程不是免除义务。[P1]
3. 个人主体是当前最大约束之一：微信现行官方类目表的个人部分不含“深度合成（AI 问答/AI 创作）”，它们列在非个人主体表中。不能把 AI 总结、问答、出题换名为“备忘录”规避实质类目。[P2]
4. 先开发可离线验证的个人学习工具：课程、文本资料、手动疑问与答案、手工复习卡、间隔复习、回收站、备份。它仍需按实际功能选择可用类目、完成备案/审核/隐私说明；不是“本地版自动免审”。
5. AI 学习包、复杂文档解析、实时课堂语音与云同步，应另立后续阶段；需要主体资格、隐私、后端安全和设备验证均通过。**不采用审核时隐藏、审核后远程开启的方案。**
6. 本次首版是工程起点，不是完整 App 移植，也未正式发布。核心80项+页面53项测试通过（共133项），8个WXML和9个WXSS编译通过；游客AppID被开发者工具拒绝，模拟器/真机与动效性能尚未验证。具体验证记录见 `../miniprogram/README.md`。

## 二、知习现在实际上有什么

源码盘点而非仅看宣传页。Android 主要入口是“听课 / 学习 / 复习 / 设置”，并非课表管理或番茄钟产品。

| 能力 | 现有实现事实 | 小程序影响 |
|---|---|---|
| 听课 | 本地 sherpa-onnx 流式/终稿识别、前台服务、暂停继续、手动标疑问；云端 Lecsync Realtime | 无法直接带入 Android Service、ONNX native runtime；短录音/音频上传另设计，不承诺后台整节课 |
| 翻译 | 逐段字幕翻译、双语与术语、云端说话人和纪要 | 需要服务端、额度、网络恢复和相应类目核验 |
| 学习 | 课程、讲义、课堂记录、7 类学习内容、人工编辑与导出 | 普通数据操作能重写；本轮只做本地文本与手工卡片子集 |
| AI 学习包 | SESSION/MATERIAL/EXAM 模式，纪要、疑问答案、重点、词汇、短语、问答、练习，附来源 | 后端协议可以复用；个人主体资格不是技术问题可替代 |
| 文档 | PDF/图片/TXT，Android PdfBox/ML Kit；服务端页图/OCR/视觉处理 | 小程序文档预览不等于提取、批注或视觉理解；不可伪称已支持 |
| 复习 | java-fsrs，四档评分；Web 使用 ts-fsrs；TTS 与 CET6 CSV/TSV 导入 | 算法可正规移植，但现有 JS 文件只是外部库包装；零依赖本轮不是 FSRS |

| Android 特有 | Keystore、通知栏操作、桌面小组件、系统 TTS、文件选择与导出 | 要设计替代交互，不能百分百等价 |

## 三、功能能还原几成

### 口径与估算

下面是**工程预估区间，不是已实现比例、实测评分或微信承诺**。以十类用户能力为粗粒度参照：课程资料、手动疑问/内容、复习与词表、历史与导出、多格式文档、AI 学习包、账号同步、云端实时课堂、离线/后台语音、Android 系统集成。每类权重近似，实际应由用户最重视的场景重新加权。

| 口径 | 估算 | 条件 |
|---|---|---|
| 以“课程—学习内容—复习”学习端为主的完整目标版 | **8–9 成** | 完成 FSRS、分类/编辑/导入与云端必要能力；合适主体与服务资质、后端整改、测试到位 |
| 把离线听课、长时间后台录音、系统集成都算进去的完整 App | **7–8 成** | 业务替代而非逐项 1:1；AI 等具备准入条件；保留 Android 承接重语音场景 |
| 个人主体、审慎排除不开放 AI 类目后的实用版上限 | **约 4–6 成** | 主要是资料整理、手动学习、复习、备份；其余依实际类目确认，不能承诺批准 |
| **本次实际开发的 0.1 本地首版** | **粗略约 2–3 成完整 App 范围** | 课程/手动文本/疑问/手工卡/简单排期/回收站/备份；不含 AI、FSRS、语音、PDF/OCR、云同步；不等于上线完成度 |

首版不应写成“功能还原 80%”：那是有条件的后续目标，不是本次交付。

### 逐类迁移路线

- **容易接近原体验**：课程列表、文本资料、手动疑问、内容浏览、编辑/搜索（后续）、卡片、四档评分、分类、空状态、导出。
- **可做但要补工程**：正规 FSRS、词表导入、文档处理任务、AI jobs 断点恢复、微信身份与原账号绑定、跨端同步。不能把 `fetch/Dexie/React` 原样粘贴进小程序。
- **只能业务替代**：任意文件选择→微信会话选文件；系统 TTS→经核验的服务/插件或不提供；本地通知→有条件订阅消息/日历；长语音→用户主动上传与任务恢复。
- **不承诺等价**：Android 后台前台服务、桌面组件、Keystore、本地重型识别模型、任意第三方 App 跳转、持续通知栏操作。

## 四、丝滑动画能还原几成

### 原 App 的具体依据

源码视觉 token：品牌橙 `#FF670D`、深橙 `#E04E00`、浅底 `#FFF1E8`、文字 `#171717/#6F6F6F`、背景 `#FCFCFC`、描边 `#E6E5E3`。常见面板 28dp、卡片 24dp、左右留白 20dp。

- 页面进入：400ms，`cubic-bezier(0.05,0.7,0.1,1)`，淡入+横移约 1/5 屏+0.96→1 缩放；退出 160ms。
- 复习卡：Y 轴翻转 420ms。
- 按压：0.86–0.9 的弹簧缩放。
- 高版本 Android 玻璃：backdrop blur/lens/vibrancy，与系统版本有关；低版本已有静态表面降级。

源码位置：`MainActivity.kt:1560–1623`；`app/src/main/java/com/classroomradar/app/LiquidGlass.kt:65–179`；`app/src/main/java/com/classroomradar/app/learning/ReviewSessionScreen.kt:96–100`。不能把参数抄过去就当实测同等流畅。

### 评估

- **视觉风格目标 8–9 成**：颜色、布局节奏、圆角、字阶与橙色导航容易对齐。
- **常规动画目标 7–9 成**：淡入、缩放、卡片翻面、普通弹层可用 transform/opacity；真机表现取决于节点量、文本、数据更新和设备。
- **把玻璃折射、交互式路由、精细手势都计入的整体动效，保守目标 6–8 成**。不要承诺 Android 级模糊/折射和所有设备稳定 60/120fps。
- **本轮没有测得动画还原度或帧率**。已写 400ms 页面淡入/轻位移、420ms 翻卡、按压反馈、自定义底部导航和减少动画开关；不是 App 的全部交互路线。

首版使用原生页面的 **WebView 渲染引擎**，不是嵌入网页的 `web-view` 组件。后者个人主体官方不支持，两者不要混淆。[T1]

Skyline 后续单页对照实验：Worklet 动画仅 Skyline；跨页共享元素和自定义路由要求连续 Skyline 页面；CSS/组件存在差异。glass-easel 是组件框架，不是玻璃特效。[T2–T5] 官方兼容页和起步页版本表不完全一致，必须能力检测并核对实际 `this.renderer`，不写“某一版本以上全部支持”。

性能验收建议：低/中/高档 Android + iOS，记录设备/系统/微信/基础库/渲染器/数据量；固定长列表、键盘、翻卡、备份、前后台场景；观察 p95 响应、慢帧与长卡顿。60Hz 的 16.7ms 是预算，不是现有结果。目标可设点击反馈 p95≤100ms，但须真机测量才能宣布达到。

## 五、WorkBuddy 打包到底能不能免审核、免备案

官方《小程序开发与发布》页面本次显示更新于 2026-11-10。[P1]

| 名称 | 实际含义 | 能否当成公开上线 |
|---|---|---|
| 本地开发/开发版 | 开发者工具和授权开发者验证代码 | 不能 |
| WorkBuddy 试用小程序 | 文档写临时 AppID，有效 14 天、最多 15 名体验者；不能代注册长期运营账号 | 不能；以工具当前规则为准 |
| 体验版 | 上传后供配置的体验成员访问，不是提交正式代码审核后的公开版 | 不能拿来长期面向公众经营 |
| 正式版 | 自有合格主体账号，上传→提交微信审核→通过→发布 | 需要备案、审核和对应资格检查 |
| 第三方平台托管 | 授权服务商代做上传/提审/发布 | 不改变主体责任、服务类目和审核规则 |

**“无需审核”通常指有限测试版本，不是正式版豁免。** 文档还明确正式版更新需重新审核。WorkBuddy 生成代码、托管部署、云函数/数据库或其套餐的收费，不等于微信的认证费用、法定备案或业务许可。

本次没有授权 WorkBuddy 托管账号，没有向其上传知习源码或课堂数据，没有注册/付费/提审/发布。

## 六、个人主体的真实上线边界

微信《小程序开放的服务类目》本次页面最后编辑 2026-11-03。[P2]

- 个人“教育”部分为**教育信息展示**，明确不支持教育视频播放/直播、课程产品销售。不能据此推断所有教育产品均可运营。
- 个人“工具”包含办公、信息查询、备忘录等；备忘录范围强调不涉及原创内容传播及公开访问。**知习应根据真实功能和后台可选项选择，不保证某一个类目必过。**
- “深度合成—AI 问答 / AI 创作”列在非个人主体表；个人表未列。对当前 AI 总结、生成问答和练习的产品形态，不能按个人普通工具路线直接宣称可发布。
- 非个人 AI 问答的第三方技术路径，官方表列算法备案主体证明及合作协议，包含算法名称、应用场景、备案编号等。仅购买一个大模型 API Key 不是自动具备全部材料。
- 录音、普通词典翻译、AI 翻译、生成式问答、ASR 不应一概当同一类业务；最终以技术路线、内容呈现、主体和平台反馈确认。
- 没有公开作品、社区、评论和分享学习正文的首版，避免引入 UGC 公开传播；将来新增必须重做审核、举报、版权/侵权、内容安全设计。

**建议分产品阶段，而非隐蔽开关：**个人本地学习版正常备案审核；需要 AI 主能力时，再评估符合要求的主体/类目/供应商合作材料并提交包含真实功能的版本。企业或个体工商户也不自动获得 AI 资格。

## 七、备案、认证、审核、域名备案不是同一件事

| 事项 | 谁负责/何时需要 | 本项目判断 |
|---|---|---|
| 主体注册与实名 | 小程序账号与管理员信息 | 需要真实主体；不向聊天发送身份证、验证码或 AppSecret |
| 微信认证 | 平台的主体认证服务/特定能力条件 | 与实名不同；准确资格、费用、周期以后台为准，不杜撰个人30/企业300等固定价格 |
| **小程序备案** | 工信部移动互联网应用程序备案体系，由平台接入审核流程 | 正式上架需完成；纯本地/无自有服务器不自动豁免小程序备案 |
| **代码/内容审核** | 微信审核实际功能、类目、内容、权限、隐私与体验 | 备案通过不等于代码审核通过；更新也可能需审核 |
| 服务器域名 ICP 备案 | 微信普通公网通信域名及中国境内互联网信息服务的相应要求 | 云端启用前核验；现有 App 域名能访问不等于已满足小程序域名规则 |
| 增值电信/行业许可、前置审批 | 取决于实际业务性质、经营模式与行业 | 不是所有学习工具都必须办“ICP许可证”；也不能认为有备案号就可经营所有业务 |

微信备案指引：[P3]。当前展示流程为信息填写→平台初审通常 1–2 工作日→收到 12381 短信后 24 小时内核验→管局通常 1–20 工作日→取得备案号；补正、地区差异等会影响总周期，不能承诺几天一定上架。FAQ 直接列错误码 86369：“小程序上架需先完成备案”。备案信息变化应及时变更。[P4]

备案号在小程序更多资料页的展示按平台流程执行；如官方当前另要求产品内展示/链接，发布时以后台说明补齐。不用购买 WorkBuddy 来换取所谓备案豁免。

证据边界：本轮成功核实的是微信官方备案实施指引与FAQ；未独立成功读取工信部2023年APP备案通知原文全文，不将平台引用冒充本次逐条法律原文核验。

费用口径：本次零新增 npm 依赖、未采购服务器/短信/模型/工具套餐；未产生授权的发布或认证费用。微信官方认证页本次未足以核实网上流传的个人/企业固定报价，故列为**待后台核实**，不要拿第三方文章价格当预算承诺。[P5]

## 八、隐私与 AI 合规清单

### 本地首版

- 只保存主动输入文本、课程、疑问、手工卡片与评分、动画偏好；无账号、麦克风、定位、广告、统计 SDK 或开发者服务器请求。
- 真实教师/学生姓名、录音、课堂内容不要当测试材料；本轮示例均为人工合成。
- 缓存可能因删除小程序、微信清理/空间不足丢失；明确“本机保存”不是永久保管或跨设备同步。
- 导出 JSON 未加密且含回收站。先本地生成，再由用户直接点击分享并选择会话；不能自动上传或后台发给联系人。
- 回收站是软删除而非彻底删除；备份副本也不会随本机清除撤回。
- 上架前补齐运营者姓名/主体、有效联系方式、权利响应/投诉机制，按实际接口填写微信隐私保护指引；开发版内的行为说明不能替代正式隐私政策。[P6]
- 微信运营规范要求提供修改、删除用户数据的方式。当前首版只有软归档与疑问答案修改；正式发布前须补齐课程/资料/卡片修改和清晰的数据删除/清空机制、备份副本处理说明，不能仅有回收站就宣称完全满足。[P10]

### 若以后加云端

- 分别说明原始音频、转写、讲义页图、AI 输入/输出、日志、账号、同步数据的处理目的、接收方、存储地点/期限和删除方式；不能照抄“服务端不保存正文”。
- 上传、AI、云录音、同步分别主动触发；最少权限、拒绝可继续本地学习。第三方模型密钥与 AppSecret 只在后端。
- 用户注销与删除要覆盖绑定、云资料、任务结果、页图、备份/日志保留例外；不能只删本机 token 就声称删除账号。
- 面向境内公众的生成式 AI 服务按《生成式人工智能服务管理暂行办法》等适用范围评估；并非每个普通学习工具都必须自建模型备案，也不是调用已备案模型就自动免除应用侧义务。[P7]
- 《人工智能生成合成内容标识办法》2025-09-01 起施行，明确文本/音频/图像等标识与下载、复制、导出场景要求。仅 UI 写“AI 生成”不当然覆盖文件隐式标识义务；按实际内容类型与标准实现。[P8]
- 不把“特定无显式标识例外条件下保存相关日志不少于6个月”误写为所有用户聊天正文一律存6个月。[P8]
- 对具有舆论属性或社会动员能力等情形的算法备案/安全评估，以及深度合成服务/技术支持者义务，需按实际角色核验。公开发布用户内容另需审核、举报与侵权处理。[P7][P9]

## 九、后端不是直接接上就算完成

本次只读核对发现以下接入前必须处理的事项，未修改或部署后端，也未访问生产数据：

## 十、本次架构与实现范围

目录 `miniprogram/`，本地分支 `feat/wechat-miniapp`。未提交或推送 GitHub。

- 原生 `App/Page/Component`，主包、默认 WebView 渲染；无新 npm 依赖，无云 SDK、录音、网络请求、隐藏 AI 开关或 H5 容器。
- 七页面：学习首页、复习、我的、课程详情、学习资料详情、通用手动编辑表单、隐私与版本边界；另有自定义三项底部导航。
- 按实体生成 UUID v4，仅作本地标识，不冒充安全令牌；外键用 UUID，不依赖自增 ID。
- 单 JSON 快照存储，schema version 1；每次校验完整草稿并一次写入，成功后发布内存状态；失败不先修改内存。存储适配层需遵守单 key 原子替换语义。
- 为避开微信单 key 1MB 上限，整个序列化快照硬限 **750KiB UTF-8**，备份输入限1MiB，还有实体/字段上限。适合小规模验证，不是长期大课堂数据库；回收站不会释放容量。后续应版本化分片/文件存储，而非偷偷删旧资料。[T6]
- 回收站明确父子依赖顺序：先卡片/疑问/资料，再课程；恢复先父；复习历史保留。
- 备份严格校验版本、枚举、日期、关联、日志；白名单重建对象；完全相同 ID 跳过，冲突拒绝，不覆盖本机；不支持直接导入 Android/网页数据库。
- `spaced-interval-v1`：不认识1分钟；模糊至少10分钟/原间隔×1.2；认识至少1天/×2；很简单至少3天/×3；最高365天。明确**非FSRS**。
- 课程/资料/卡片目前以新增、查看、归档恢复为主；疑问可填/改答案。尚未实现原课程/资料/卡片通用编辑、搜索、CET6导入、七分类完整页面，不能称完整CRUD。

## 十一、接下来的发布路线与验收门槛

### A. 当前本地首版（已开发，具体验证见 README）

### C. AI / 课堂云端版本（有条件、尚未开发）

### D. 动效增强（独立性能实验）

基线真机测量→选复习或列表一页尝试Skyline/Worklet→明确旧端静态/普通路由降级→相同设备数据A/B→仅收益可证实时推广。不为了“看起来高级”给首版全面引入双渲染维护成本。
